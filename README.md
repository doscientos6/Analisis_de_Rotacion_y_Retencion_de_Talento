# Análisis de Rotación de Empleados (IBM HR Analytics) - Fase SQL

Este proyecto es parte de mi formación como Analista de Datos. El objetivo principal de esta etapa fue establecer una base sólida antes de pasar a la visualización, asegurando la integridad de los datos para asegurar una visualización efectiva posteriormente.

## 🛠️ Tecnologías
- SQL (PostgreSQL)

## 📋 ¿Qué hice en esta etapa?
1. **Modelado**: Creación de la estructura de la tabla (DDL) asegurando tipos de datos correctos.
2. **Auditoría**: Validación de la integridad de los datos, buscando valores nulos e inconsistencias.
3. **Exploración**: Consultas iniciales para entender el comportamiento de la variable `Attrition` y el volumen total de la muestra.

## 📁 Estructura del código
- `queries.sql`: Contiene el DDL para crear la tabla y las consultas de validación y análisis exploratorio.
